## Tips

1. **Be specific** — vague goals lead to scope creep
2. **Name non-goals** — prevents agents from adding unrequested features
3. **Quantify success** — "increase engagement" is weak; "increase daily active users by 20%" is strong
4. **Update regularly** — as the project evolves, update this file
5. **Cross-reference** — link to PRD, architecture docs, and design files
