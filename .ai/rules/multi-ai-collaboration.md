# Multi-AI Collaboration Rules

- Assume another model may continue your work with no chat history.
- Keep `PROJECT_STATUS.md` dashboard metrics and detailed log current.
- Leave clear handoff notes in `.ai/memory/handoff.md` before stopping.
- Prefer project files over hidden chat context.
- Record decisions as ADRs in `.ai/context/decisions/` so the "why" isn't lost.
- Cite commands run and verification results.
- Do not claim completion without evidence.
- Do not overwrite another agent's work without first understanding it.
