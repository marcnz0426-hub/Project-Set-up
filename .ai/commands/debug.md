# Command: Debug

Use when there is a bug, failed test, flaky behavior, or unexpected result.

1. Read `.ai/memory/index.md` first.
2. Open only relevant detailed memory files from `.ai/memory/`.
3. Use the Debugger persona.
4. Use systematic debugging.
5. Reproduce the issue when possible.
6. Identify root cause before changing code.
7. Verify the fix.
8. Log the fix concisely in `.ai/memory/bug-log.md`.
9. Update `.ai/memory/index.md`.
10. Run `.ai/commands/prune-memory.md` if any threshold is exceeded.
