## Loading Rules

1. **Always read** purpose.md and INDEX.md at session start
2. **On-demand read** architecture.md, domain.md, and design files based on task type
3. **Size-aware loading**: Files > 500 lines → read Summary section first, then specific sections
4. **Cross-reference**: Check for conflicts between files before planning
5. **Update status**: Log what was read in PROJECT_STATUS.md before proceeding
