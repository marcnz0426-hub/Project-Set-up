# Memory Archive

This folder stores old resolved memory that should not stay in active context.

Agents should not read archive files by default. Read them only when `index.md` points to a relevant archived topic or when investigating a repeated historical issue.

Recommended archive files:

- `bug-log-YYYY.md`
- `fix-patterns-archive.md`
- `lessons-archive.md`

Archive entries should remain concise. If an archived entry is never useful and has no recurring value, it may be permanently deleted.
